What ns3-thz-ntn does

thz-ntn is an ns-3 module for sub-terahertz and terahertz non-terrestrial links from 100 GHz to 1 THz, with atmospheric loss built from ITU-R P.676-13 Annex 1 line-by-line absorption over P.835-6 reference atmospheres plus P.838-3 rain, P.840 cloud and fog, and P.618-13 scintillation. It adds ultra-massive MIMO arrays with beam squint, reconfigurable intelligent surfaces, EKF beam tracking, ISAC and inter-satellite links, and exposes the losses as ns-3 PropagationLossModels that attenuate real packets.

Accompanying studyDeviation of Simplified Gaseous Absorption Models From Recommendation P.676-13 on Low-Earth-Orbit Slant Paths From 340 to 850 GHz. Code and data are in this repository.

What it models

The absorption engine, ThzNtnMolecularAbsorption, implements ITU-R P.676-13 Annex 1 with 44 oxygen and 35 water-vapor lines, integrated along a straight ray over the six P.835-6 reference atmospheres; a WaterVapourScale attribute scales the humidity profile for column sweeps. Weather terms follow P.838-3 for rain, P.840 for cloud and fog, and P.618-13 for amplitude and phase scintillation, with P.681-11 land mobile satellite and other per-recommendation reference classes unit-tested against ITU-R values. Free-space loss, pointing error and a composite cascade (ThzNtnChannelModel) complete the analytic channel.

Above the channel, the module provides UPA, UCA and Cassegrain arrays with a DFT codebook and wideband beam-squint loss, a RIS with 20 log10(N) gain under perfect CSI and phase-quantization loss, EKF or ephemeris-based beam tracking with vibration, refraction and latency pointing terms, ISAC debris ranging, inter-satellite link budgets, and alpha-mu fading. ThzNtnPropagationLossModel carries the atmospheric excess loss onto the mmwave NR spectrum channel, where the 3GPP model caps the carrier at 100 GHz; above that, ThzNtnLinkErrorModel decodes IP packets at 300 GHz on a point-to-point link without NR PHY, MAC or HARQ. A RIS can be switched by an xApp through oran-ntn. Geometry comes from SGP4 orbits in ntn-constellation, with 3GPP TR 38.811 and TR 38.821 cited for NTN geometry and TR 38.901 for the terrestrial baseline. The hardware-impairment stage is registered but not yet applied in the cascade.

Install

Every module ships in the ready-built container image of the toolkit (version 2.7.1):

docker pull uzairdocker69/ns3-ntn-toolkit:latest
docker run --rm -it uzairdocker69/ns3-ntn-toolkit:latest bash

To build from source, clone ns3-ntn-toolkit, which vendors this module under contrib/, or follow the README of this repository (branch thz-ntn-v2).
